# Zypher Media

**Zypher Media** is a music player built for **Windows 10 Mobile**, designed around the classic **Windows Phone / Metro** aesthetic.

The project is currently in active development. More features, improvements and fixes will be added in future releases.

## 📱 Platform

* Windows 10 Mobile
* UWP (Universal Windows Platform)
* Built with C# and XAML
* Developed using Visual Studio 2017

## 🎵 Current Features

* 🎶 Music player
* ▶️ Play / pause controls
* 🔊 Volume control
* ⏩ Music progress slider
* ⏱️ Current playback time and duration
* 📁 Select music files manually
* 🏠 Home page
* 🎨 Classic Metro-inspired interface
* 📱 Designed specifically with Windows Phone in mind

## 🚧 Development Status

Zypher Media is currently an **early development build**.

Bugs are known and will be fixed in a later release.

### Known Bugs

* **Update Logs crash**
  Pressing **"Update Logs"** in the menu currently causes the app to crash.

* **Unimplemented sections**
  The following sections are not implemented yet:

  * Albums
  * Artists
  * Playlists
  * Favourites
  * Settings

* **Music folder access**
  The app currently cannot access the Windows Music folder/library.

* **Home page spacing**
  The tiles at the bottom of the Home page have significantly too much spacing between them.

## 🛠️ Planned Improvements

Future releases are planned to include:

## 🎨 Design

Zypher Media follows the **classic Microsoft Metro / Windows Phone design language**, with a focus on clean layouts, large typography and simple controls.

The Zypher Media logo uses a merged **Z + M** design, representing **Zypher Media** as a single visual mark.

## 📦 Building

The project can be opened and built using:

**Visual Studio 2017**

The application targets the **Universal Windows Platform (UWP)** and is intended for Windows 10 Mobile.

This project is still being developed, so **expect bugs and unfinished features**.

If something doesn't work correctly, it may already be a known issue listed above.
